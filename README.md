# Pal Patrol website preview

This is a self-contained, responsive one-page brand and product website for Pal Patrol. It has no build step or package installation.

## Run it

Open `index.html` in a modern browser, or use the included zero-dependency local server:

```powershell
cd .\pal-patrol-web
node .\serve.cjs
```

Then visit `http://localhost:4173`.

## Included

- `index.html` — semantic, accessible page structure
- `styles.css` — responsive visual system, product illustrations, and app mockups
- `script.js` — mobile navigation, FAQ behavior, and preview-only form feedback
- `serve.cjs` — optional zero-dependency local preview server
- `help.html` — complete Help Center landing page
- `article-connectivity.html`, `blog-emotion.html`, and `release-notes.html` — linked support subpages
- `assets/` — the user supplied, unmodified source images used throughout the site
- `IMAGE-PLAN.md` — precise image placements and art direction

## Visual translation

The provided pet-sitting reference uses a friendly green, editorial hero imagery, straightforward service cards, clear section pacing, and social proof. This build preserves the useful principles—not its template or assets—then redirects them into a contemporary pet-wellness technology system:

- **Safety + care, not a generic pet-service menu:** hierarchy starts with connection and uses location, rest, wellness, and mood as the product story.
- **A calmer premium palette:** forest green signals trust, lime creates action and live-status energy, and clay/blue make data feel caring rather than clinical.
- **Product-led storytelling:** the collar and app dashboard are visual anchors; sensor features are introduced as useful outcomes.
- **Structured navigation:** the collar, app, wellness, how-it-works, dog/cat pathways, product configuration, social proof, and FAQ are discrete modules ready to become individual routes later.

The “Add to patrol” and email form actions are intentionally non-commerce preview interactions. Connect them to your cart, CRM, or checkout when those services are selected. The Help Center search, FAQ accordions, video guide anchors, article and journal links, release notes, mail links, and response copy buttons are interactive.

## Image note

The images in `assets/` are copies of the files supplied for this project. They are used as provided and are not altered to remove or hide their visible source marks. The CSS sizes them responsively while retaining full source framing. Replace them with cleared final assets when available.
